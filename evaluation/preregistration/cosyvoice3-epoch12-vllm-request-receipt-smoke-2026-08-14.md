## Acceptance and falsifiers

Each row must retain exactly one schema 1.0.0 request receipt with the applied
sampling state, a positive output-token count, and a SHA-256 token hash. The
receipt must not retain token content. The upstream row must label its runtime
seed as generated by vLLM. The seeded row must record supplied seed 42 and
runtime seed 42.

The smoke fails if the internal hook is not observed exactly once, the pinned
vLLM version drifts, either planned row is missing, a failed row is replaced,
artifact verification fails, or a receipt retains token content.

## Scope

A pass validates only the process-local request-receipt instrumentation on the
frozen runtime and artifact. It does not establish content quality, perceptual
quality, runtime equivalence, deterministic execution, or a causal explanation
for the earlier long-form sampling effect.
